# Orbit — 30초 암산 챌린지

## 로컬 실행

`index.html`을 더블클릭해 브라우저에서 여세요. 설치, 빌드, 인터넷 연결이 필요 없습니다.

로컬 서버를 사용하려면 이 폴더에서 `python -m http.server 8000`을 실행한 뒤 http://localhost:8000 에 접속하세요.

## 게임 방법

- 쉬움: 1~10의 덧셈·뺄셈 / 보통: 1~20의 덧셈·뺄셈과 구구단
- 30초 동안 답을 입력하고 Enter 또는 정답 확인을 누르세요.
- 정답 10점, 3연속 정답마다 5점 추가. 오답은 연속 기록만 초기화됩니다.
- 최고 점수는 브라우저에 저장됩니다. 저장이 제한된 환경에서도 게임은 실행됩니다.
- 탭을 옮겨도 제한 시간은 계속 흐릅니다.

첨부 DESIGN.md의 검정 바탕, 보라색 CTA, 가벼운 타이포그래피와 삼각형 파티클을 반영했습니다. 폰트 파일이 제공되지 않아 기기에 설치된 Inter, Segoe UI, 맑은 고딕 순으로 사용합니다. 외부 배포와 Sites 등록은 하지 않습니다.
