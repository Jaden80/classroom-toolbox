# 모둠 퀴즈 레이스 디자인 초안

## 목표와 사용자
교사는 교실 큰 화면에서 6모둠 상태를 즉시 파악하고 학생은 기기에서 문제에 집중한다. 밝고 읽기 쉬운 2D 경주 분위기. 참고 사이트의 자산·로고·실차 모델을 복제하지 않는다.

## 필수 원칙
- 교사: 6개 고정 레인, 자동차·모둠 번호·이름·점수·현재 문제·완료 여부.
- 학생: 문제·보기·선택·제출·피드백·다음. 전체 경주 없음.
- 자동차 위치는 정답 비율. 문항 완료 여부와 경주 거리는 별도 표현.
- 순위는 정답 수·풀이 시간 기준이며 실시간 순위는 잠정임을 명시.

## 제안 색상과 글꼴
배경 #F8FAFC, 카드 #FFFFFF, 본문 #0F172A, 보조 #475569, 기본 버튼 #1D4ED8. 모둠색: 파랑·주황·초록·보라·청록·분홍. 모둠색은 장식에 사용하고 본문 대비는 별도 검사한다. 색상만으로 정오답·모둠·순위를 구분하지 않는다.

시스템 한글 sans-serif, 외부 폰트 요청 없음. 본문 18px, 문제 24~32px, 교사 주요 수치 28px 이상을 기본으로 기기별 조정한다.

## 레이아웃과 컴포넌트
8px 간격 체계, 카드 내부 24px, 모서리 12px, 터치 영역 최소 44px를 제안한다. 교사 화면 상단 코드·상태, 중앙 트랙, 하단 현황과 종료 조작. 모둠 화면은 한 열 카드·큰 보기 버튼. 공통: 라벨 있는 입력, 보기 선택 그룹, 기본 버튼, 오류 요약, 상태 배지, 결과 표, 삭제 확인 안내. 정답과 해설은 일반 문자열로 렌더링한다.

## 화면 상태
빈 상태는 다음 행동을 안내한다. 로딩은 실제 처리 중에만 표시한다. 제출 요청 중 이중 제출을 막고 응답 소실 시 서버 확정 상태를 확인한다. 단절 시 `연결이 끊겼습니다. 다시 연결하는 중입니다`와 마지막 갱신 시각을 표시한다. 저장·삭제 성공은 서버 확인 후 알린다. 결과 화면에 `닫으면 이번 모둠 기록이 삭제됩니다`를 표시한다.

## 반응형과 접근성
모둠 화면 360px, 교사 화면 1280×720부터 검증. 작은 교사 화면은 표 스크롤을 허용하되 종료 조작 유지. 키보드 보기 선택·제출 가능, 문제 전환 시 제목 초점, 눈에 보이는 포커스, 200% 확대 지원, 일반 텍스트 대비 4.5:1 목표. 자동차는 직접 작성 SVG 또는 CSS 도형. 이동 300~500ms 제안, prefers-reduced-motion 시 즉시 이동. 장식의 반복 화면 읽기와 초당 상태 알림을 피한다.

## 금지 사항과 확인 목록
- 점멸·자동 소리·과도한 축하 애니메이션·3D 엔진·작은 조작 버튼 금지.
- 학생 실명·이메일·서버 내부 오류·기술 설정을 풀이 화면에 노출하지 않는다.
- 서버 미연결 데모에 실제 접속·복구·삭제 완료 문구를 표시하지 않는다.
- 6레인 식별, 큰 화면 가독성, 오답 해설, 순위·시간, 모바일·키보드·대비·동작 줄이기를 검증한다.
