# 단계별 제작 계획과 구현 프롬프트

상태: 구현 전. 아래 공통 지시와 해당 단계 하나를 AI 코딩 도구에 전달한다. 이전 단계 검증 결과와 실제 파일을 확인하고 이어서 진행한다.

## 공통 지시

```text
이 폴더의 개발명세서.md와 DESIGN.md를 먼저 읽고 모둠 퀴즈 레이스를 구현해줘.
기존 작업공간 프로그램은 덮어쓰지 말고 독립 하위 프로젝트로 만들어줘.
한 번에 아래 지정한 단계만 구현하고 실행·검증한 뒤 결과를 보고해줘.

사용자는 교사 1명과 최대 6모둠이며 모둠별 기기 1대다. 인터넷 웹앱,
교사 이메일 로그인, 학생은 코드·가명으로 입장한다. 문제는 엑셀의
번호/유형/문제/보기1/보기2/보기3/보기4/정답/해설을 검증해 저장한다.
객관식과 OX, 동일 문항 순서·모둠별 속도, 오답 정답·해설,
정답 수 우선·동점은 서버 풀이 시간, 완전 동률 공동 순위를 지켜줘.
교사 화면만 6레인 경주와 모둠 현황을 표시하고 모둠에는 문제만 보여줘.
조기 종료 미응답은 0점, 접속 중단 시간 포함, 같은 기기 토큰으로 복구해줘.
문제는 영구 재사용하고 모둠 기록은 결과 닫기·만료 정책에 따라 삭제해줘.

기술 제안은 TypeScript·Vite·HTML/CSS/SVG, Supabase Auth/서버 함수/PostgreSQL,
Cloudflare Pages다. 실제 최신 공식 문서·무료 한도·파서 공급원을 확인해
안전한 버전을 고정하고 불필요한 프레임워크는 추가하지 마.
교사 계정은 사전 허용하고 공개 가입은 제외해줘. 익명 DB 접근은 막고
채점·시각·정원·중복 제출·종료 경합은 서버 트랜잭션에서 처리해줘.
미래 문제의 정답·해설을 학생에게 보내지 마. 토큰은 고엔트로피,
서버에는 해시 저장, 브라우저 보관값은 방 만료 시 제거해줘.
실제 학생 정보·추적 분석·외부 AI는 사용하지 마.
비밀키는 서버 환경변수, .env.example에는 자리표시자만 사용해줘.

필수 검증: 6모둠 전체 흐름, 엑셀 오류, 공동 순위, 동시 제출·종료,
재접속, 권한 우회, 정답 유출, 만료·삭제, 360px/대형 화면,
키보드·대비·동작 줄이기. 필요한 테스트를 단계에 맞게 작성해줘.
소스·의존성 파일·README·설정 예시·DB 마이그레이션·검증기록을 제공해줘.
외부 계정 생성·배포·결제는 별도 요청 전 실행하지 마.
단계 완료 시 변경 파일, 실행 방법, 실제 검사 결과, 미확인 사항을 보고해줘.
데모·미연결 기능은 명확히 표시하고 구현하지 않은 기능을 성공으로 가장하지 마.
```

## 1단계: 화면과 규칙

```text
공통 지시에 따라 1단계를 구현해줘. 먼저 기존 파일·AGENTS.md와 명세를 확인해줘.
가상 모둠 6개, 객관식·OX 예시로 교사 6레인 화면과 학생 문제 화면을 만들어줘.
채점·정답 수·서버시각을 입력받는 순위 계산·공동 순위·자동차 비율을
독립 함수로 작성하고 테스트해줘. 가상 상태를 실제 서버 동기화로 표현하지 마.
화면 미리보기와 시작 명령, 통과한 규칙 검사를 제공해줘.
```

## 2단계: 인증과 서버 무결성

```text
1단계 결과를 확인하고 서버·DB·교사 인증을 연결할 코드를 구현해줘.
마이그레이션, 소유권 정책, 교사 허용 계정, 문제 비공개 스키마,
불투명 모둠 토큰, 현재 문제·답안 제출 API를 만들어줘.
서비스 비밀키는 서버에만 두고 점수·시간은 서버에서 결정해줘.
문항 1회 확정, 멱등 요청, 종료와 제출 트랜잭션을 검증해줘.
인프라 자격증명이 없으면 로컬 검증 범위와 연결 절차를 명시해줘.
외부 운영 계정 생성이나 배포는 하지 마.
```

## 3단계: 엑셀과 문제 보관

```text
엑셀 템플릿 다운로드·선택·미리보기·행/열 오류·일괄 저장을 구현해줘.
개발명세서의 정확한 헤더·유형·정답 값·빈 행·수식 금지·크기 기준을 지켜줘.
실제 XLSX 템플릿과 정상/오류 검증용 가상 파일을 만들어 읽기 검증해줘.
문제 세트 목록·이름 변경·삭제·재사용을 제공하고 서버에서도 검증해줘.
원본 파일은 서버 저장소에 남기지 말고 진행 중 방은 불변 스냅샷을 사용해줘.
```

## 4단계: 실제 6모둠 경주

```text
방 생성·코드·입장·대기·시작·동일 순서 개별 속도 풀이를 연결해줘.
최대 6모둠 정원은 동시 입장 트랜잭션으로 보장해줘.
교사는 6레인·잠정 순위·현재 문제·정답 수·완료를 보고,
학생은 문제·보기·피드백만 보게 해줘. 시작 후 신규 입장은 차단해줘.
교사 1세션과 분리된 모둠 6세션으로 서로 다른 속도와 오답을 검증하고,
실제 서버 연동과 시뮬레이션 검증 결과를 구분해줘.
```

## 5단계: 종료·복구·삭제

```text
전 모둠 완료·조기 종료·공동 순위·서버 경과시간을 구현해줘.
같은 브라우저 토큰으로 복구하고 응답 소실·중복 탭·종료 경합을 시험해줘.
결과 확인 후 교사가 닫으면 방·모둠·답안·문제 스냅샷을 삭제하고
저장 문제 세트는 남겨줘. 결과 최대 30분·방 절대 6시간 만료와
5분 주기 정리 작업을 구현하고 만료 즉시 API 접근을 차단해줘.
오프라인 브라우저·제공자 백업까지 원격 즉시 삭제한다고 주장하지 마.
실제 DB 잔존·토큰 무효화·삭제 실패 처리 검증 결과를 제공해줘.
```

## 6단계: 운영 준비와 인수검사

```text
명세 AC-01~15를 대조하고 완료·실패·미검증 근거를 기록해줘.
무료 호스팅·DB·SMTP의 현재 공식 정책, 휴면 중지, 발송 제한을 확인해줘.
재설정 메일 실제 수신과 재로그인을 시험할 절차를 제공하고,
배포하지 않고 배포 가능한 빌드·마이그레이션·환경변수 예시·README를 정리해줘.
학교 실기기 6모둠·네트워크·큰 화면·접근성·성능 검증은 실제 수행 여부를 밝혀줘.
무료로 충족하지 못한 기능은 제한을 명시하고 자동 결제·기능 축소를 하지 마.
사용자가 별도로 배포를 요청할 때 적용할 배포·롤백 절차를 적어줘.
```
