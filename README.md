# 교실 도구함

초등교사용 도구 허브에 교실 타이머, PDF 글자 수, 모둠 퀴즈 레이스가 있습니다. 타이머와 PDF는 계정 없이 브라우저 안에서 처리하고, 퀴즈 경주는 별도 서버와 교사 계정을 사용합니다. PDF.js 6.4.299를 로컬 자원으로 포함했습니다.

## 실행

**Node.js 24 이상**을 설치하고 이 폴더의 **실행.bat**를 실행하세요. 처음에는 퀴즈 경주 의존성을 설치하고 화면을 빌드합니다. 이어서 허브(8000)와 퀴즈 경주(4317)를 함께 실행합니다.

실행 준비가 끝난 후에는 이 폴더에서 다음 명령으로도 켤 수 있습니다.

```powershell
node hub-server.mjs
```

브라우저에서 http://127.0.0.1:8000 에 접속하세요. 종료는 터미널에서 Ctrl+C이며 퀴즈 경주 서버도 함께 종료합니다. 기존 Python 정적 서버나 퀴즈 경주 실행 창이 같은 포트를 쓰고 있으면 먼저 닫으세요. 포트 변경은 HUB_PORT·QUIZ_PORT 환경변수로 지정합니다. JavaScript 모듈을 사용하므로 index.html 더블클릭 대신 HTTP로 실행하세요.

허브의 **모둠 퀴즈 레이스**를 누르면 교사 화면이 새 창으로 열립니다. 최초 교사 계정을 만든 뒤 엑셀 문제를 등록하고 수업을 열 수 있습니다. 인터넷에서 학생들이 접속하는 운영 배포는 별도 설정이 필요합니다. 자세한 내용은 `퀴즈경주/README.md`를 참고하세요.

허브 서버는 공개 화면 자원만 제공하며 퀴즈 DB·환경변수 파일·서버 소스를 HTTP로 공개하지 않습니다. 타이머·PDF만 따로 쓰는 경우에는 기존 Python 정적 서버도 가능하지만, 퀴즈 경주 연결에는 통합 실행기가 필요합니다.

## 사용

1. 허브에서 ‘교실 타이머 열기’를 선택합니다.
2. 분·초를 입력하거나 1·3·5·10분을 고릅니다. 기본값은 5분이고 허용 범위는 1초~99분59초입니다.
3. 시작, 일시정지, 계속하기, 초기화를 사용합니다. 초기화는 마지막 유효 설정으로 돌아갑니다.
4. 전체화면을 누르면 시간과 제어 버튼을 크게 보여줍니다. Esc 또는 확대 종료로 돌아갑니다. 전체화면 권한이 없으면 화면 안에서 확대합니다.
5. 종료 시 00:00과 완료 문구, 짧은 종료음이 나옵니다. 종료음 버튼으로 음소거할 수 있습니다.

진행 중 허브로 이동할 때 종료 여부를 확인합니다. 새로고침·탭 종료 시 타이머는 복구되지 않습니다. 다른 탭에서 돌아오면 종료 시각에 맞춰 보정하지만 PC 절전·브라우저 종료 중 정시 알림은 보장하지 않습니다. 기기 시계를 바꾸면 계산에 영향을 줄 수 있습니다. 스피커 음량과 브라우저 소리 권한을 확인하세요.

모든 자원은 로컬에 있습니다. 초기 로드 후 네트워크가 끊겨도 타이머는 동작합니다. 최초 오프라인 접속, 설치형 PWA, 백그라운드 알림은 지원하지 않습니다. 개인정보·사용 기록을 저장하거나 외부로 전송하지 않습니다.

## 파일과 새 도구 추가

- index.html: 허브·타이머 화면
- style.css: 디자인 토큰·반응형·전체화면 스타일과 정적 삼각형 장식
- app.js: 화면 연결·경로·브라우저 오디오·전체화면
- js/tools.js: 도구 목록
- js/timer.js: 독립적인 시간 계산·상태 전이
- tests/timer.test.js: 시간 계산 자동 검사
- 개발명세서.md: 요구사항과 인수 조건
- previous-orbit/: 작업 전 존재하던 암산 게임의 원본 보관

새 도구는 js/tools.js에 고유 id·이름·설명·route를 추가합니다. 내부 화면은 해당 화면과 경로 처리를 app.js에 연결하고, 별도 서버 도구는 hub-server.mjs에 연결 경로를 제공합니다. newWindow가 true이면 새 창으로 열립니다. 목록 데이터만 추가하면 화면이 생기는 것은 아닙니다. 타이머 로직은 별도 모듈이므로 다른 도구를 위해 수정할 필요가 없습니다. 도구 등록·수정 화면은 제공하지 않습니다.

## 디자인

디자인 참고 자료의 검정 배경, 흰색 글자, 보라색 주요 버튼, 황색 강조, 넉넉한 여백과 무테 레이아웃을 적용했습니다. 본문은 한국어와 교실 투사 가독성을 위해 400 굵기를 사용하고, 폰트는 기기에 설치된 Inter·맑은 고딕 등으로 대체합니다. 장식은 정적으로 그리며 타이머에는 표시하지 않습니다. 외부 폰트·이미지·CDN을 요청하지 않습니다.

## 검증

Node.js가 설치되어 있으면 다음 명령으로 실행합니다. npm install은 필요 없습니다.

```powershell
node --test tests/timer.test.js
node --check app.js
```

시간 경계와 잘못된 입력, 일시정지·재개, 중복 시작 방지, 종료 1회 처리, 탭 지연 보정, 초기화 후 이전 종료 취소를 검사합니다. 실제 브라우저 UI 검증 결과와 미검증 사항은 검증결과.md를 참고하세요. 자동 검사는 실제 교실 TV·전자칠판·스피커 검증을 대체하지 않습니다.

전체화면·오디오 처리 참고: https://developer.mozilla.org/en-US/docs/Web/API/Element/requestFullscreen , https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/resume


## PDF 글자 수

허브에서 **PDF 글자 수**를 선택하거나 `http://127.0.0.1:8000/#/pdf`에 접속하세요. 최대 50MB의 PDF 한 개를 선택하면 자동으로 공백 포함·제외 글자 수, 페이지별 집계, 추출 텍스트를 표시합니다. 줄바꿈은 제외하고 NFC 정규화 후 보이는 글자 단위(Intl.Segmenter)로 계산합니다. 공백 제외는 모든 공백 문자를 제외합니다. 페이지 경계에는 글자를 추가하지 않습니다.

텍스트 PDF용이며 OCR은 제공하지 않습니다. 이미지/빈 페이지는 0자 안내를 표시하고, 암호 PDF는 해제 후 선택하도록 안내합니다. 글꼴 매핑이나 문서 배치에 따라 추출 결과는 원문과 다를 수 있으니 추출 텍스트도 확인하세요. 최신 Edge/Chrome을 권장합니다.

PDF는 File.arrayBuffer로 메모리에서 읽어 PDF.js에 데이터로 전달합니다. 업로드 API, 분석 서버, 외부 CDN, 분석 도구, 브라우저 저장소를 사용하지 않습니다. CSP의 connect-src 'none'을 유지하며 문자표와 표준 글꼴도 로컬 JS 모듈로 제공합니다. 초기 앱 자원은 로컬 HTTP로 읽지만 선택한 PDF와 결과를 HTTP로 전송하지 않습니다. 지우기/취소, 허브 복귀, 새로고침 시 결과를 폐기합니다. 브라우저 메모리의 물리적 즉시 삭제를 보장하는 기능은 아닙니다.

`vendor/pdfjs/`와 LICENSE는 PDF 도구 실행에 필요합니다. 루트의 node_modules는 PDF 도구 개발용이며, 퀴즈 경주는 `퀴즈경주/node_modules`가 필요합니다. 개발 의존성 복원은 npm ci로 가능합니다. `npm test`로 글자 계산 및 타이머 검사(6개)를 실행합니다. `tests/pdf-browser-check.js`는 번들 Playwright와 설치된 Edge를 사용한 이 환경의 브라우저 검증 스크립트입니다.

## 일기장 — 하루의 조각

허브의 **하루의 조각 · 일기장**을 누르면 날짜·기분·제목·내용을 기록할 수 있습니다. 제목/내용 검색, 기존 기록 수정, 영구 삭제를 지원합니다. **일기 저장**을 눌러야 저장되며 저장 전 이동 시 확인합니다. 기존 실행 창이 있다면 종료한 후 `실행.bat`로 다시 실행하세요. 직접 주소는 `http://127.0.0.1:8000/diary`입니다.

기록 데이터베이스는 이 프로젝트의 **data/diary.sqlite**에 생성됩니다. SQLite의 `-wal`, `-shm` 보조 파일이 사용될 수 있습니다. 백업하거나 다른 컴퓨터로 옮길 때는 서버를 종료한 후 **data 폴더 전체**를 복사하세요. 이 폴더는 Git에서 제외되며 HTTP로 공개되지 않습니다. 브라우저 데이터를 삭제해도 일기는 유지됩니다. 파일 자체는 암호화되지 않으며 같은 Windows 계정/폴더 접근 권한이 있는 사람은 읽을 수 있습니다. 로그인과 여러 사용자 분리는 제공하지 않습니다. 서버는 이 컴퓨터의 127.0.0.1에서만 실행됩니다.

정적 Python 서버에서는 일기 저장 API가 없으므로 통합 실행기를 사용해야 합니다. 일기 페이지에만 로컬 API 연결을 허용하며 기존 PDF 페이지의 네트워크 차단 정책은 유지합니다. 날짜별로 여러 일기를 쓸 수 있습니다.

검증: `npm test`의 7개 검사 통과(일기 디스크 재열기/수정/삭제/잘못된 입력 포함). `node tests/diary-browser-check.mjs`는 검증 서버 8018에서 실행하는 이 환경의 Edge 브라우저 검사입니다. 허브 연결, 저장 후 새로고침, 수정, 검색, 삭제, DB 파일 접근 차단, 외부 Origin 차단, 390px 화면 가로 넘침 없음, 브라우저 오류 없음을 확인했습니다.
